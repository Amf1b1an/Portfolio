# Portfolio

## Description

This project is displaying a collection of all the other projects i've created and worked on. As of now, it is displaying projects from courses at Noroff. However, the structure of the project makes it easy to add categories and sub-categories in the future. Every project should display a thumbnail, title, description, liveLink and repoLink. Once all the criterias are met, they'll get added to the corresponding sub-category.

## Built With

- [React.js](https://reactjs.org/)
- [Tailwind](https://tailwindcss.com/)
- [Vite](https://vite.dev/)
- [TypeScript](https://www.typescriptlang.org/)

## Getting Started

Follow these instructions to clone, install, and spin up a local instance of this project on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v20 or higher recommended) installed.

### Installing

1. **Clone the repository:**

   ```bash
   git clone git clone git@github.com:Amf1b1an/Portfolio.git

   cd portfolio

   npm install

   npm run dev
   ```
